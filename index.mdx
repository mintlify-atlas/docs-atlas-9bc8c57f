The Sapiom SDK is a TypeScript/Node.js monorepo of focused packages for building production AI agents. Author agents as typed step graphs, call Sapiom's cloud capabilities (sandboxes, coding models, repositories, file storage, search, email, databases, and more) directly from your code, and ship them to the Sapiom engine via the CLI, your coding agent's MCP, or the Agent Studio desktop app.

<Note>
  The SDK is currently in **v0.x (beta)**. The API may change before v1.0.0. It is production-ready and actively maintained.
</Note>

## Get Started in 30 Seconds

<Steps>
  <Step title="Scaffold an agent project">
    ```bash
    npx @sapiom/cli agents init my-app
    cd my-app
    ```
  </Step>
  <Step title="Validate locally">
    ```bash
    npx @sapiom/cli agents check
    ```
  </Step>
  <Step title="Deploy to Sapiom">
    ```bash
    npx @sapiom/cli agents deploy
    ```
  </Step>
  <Step title="Or use Agent Studio">
    Open Agent Studio with your coding agent pre-wired and ready to go:
    ```bash
    npx @sapiom/agent-studio@latest
    ```
  </Step>
</Steps>

## Key Concepts

<CardGroup cols={2}>
  <Card title="Step Graphs" icon="diagram-project" href="/guides/step-graph">
    Agents are typed directed graphs of steps. Each step declares allowed transitions — undeclared ones are compile errors.
  </Card>
  <Card title="Pausing & Signals" icon="pause" href="/guides/pausing-and-signals">
    Steps can pause durably across processes with `pauseUntilSignal` — no compute cost while idle.
  </Card>
  <Card title="Events vs Signals" icon="bell" href="/guides/events-vs-signals">
    Events start new runs; signals resume paused ones. Two distinct namespaces that never collide.
  </Card>
  <Card title="Agent Studio" icon="desktop" href="/guides/agent-studio">
    A local web app with an embedded coding agent terminal, live canvas, and one-click deploy.
  </Card>
</CardGroup>
